# 0x-skills

Claude skills, one folder each under `skills/<name>/`.

| Skill | What it does | Status |
|---|---|---|
| [`3dui`](skills/3dui) | Live 3D product websites with three.js + Next.js: procedural geometry in real millimetres, studio lighting, scroll-directed camera, exploded views, film-style post. | Work in progress — engine done, `SKILL.md` pending |

## Use a skill

- **Claude Code (one project):** copy `skills/<name>` into that project's `.claude/skills/`.
- **Claude Code (every project):** copy it into `~/.claude/skills/`.
- **claude.ai:** zip the skill folder and upload it under Settings → Capabilities → Skills.
